feat(preset): 小泉自己的 agent preset（lily）

从内置 preset-cordis 整份复制，改两处：
1. persona 的 prefix：从「You are a coding agent」换成她的存在边界；
2. 把 water-source 挂进她自己的 preset，不再挂 profile 级 bundles。

为什么要这么改：
preset 的 plugins 是「这个 agent 挂哪些插件」的**全部**清单。
挂在 profile 级 = 所有 agent 都有 → 小泉的身份注入污染了别的会话。
挂进 preset = 只有选了这个 preset 的会话才是她。

同时从 bundles 里摘掉 @local/water-source。

附带：stripHostPrompt 可以退休了——从源头就不注入那句 coding agent。
