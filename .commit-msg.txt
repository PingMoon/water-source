fix(ui): 换宿主真实存在的 CSS 变量，暗色主题下看得清

我之前写的 --dsw-text / --dsw-border / --dsw-bg **全是不存在的**，
于是 fallback 到深色字 + 暗色背景，暗色主题下看不清。

真实变量（从 dsh-fish client.js 挖出来的）：
  --dsw-alias-label-primary / -secondary / -tertiary
  --dsw-alias-border-l2 / -l3
  --dsw-alias-bg-layer-1 / bg-l1
  --dsw-alias-label-error
  --dsw-alias-state-business-primary

fallback 也改了：文字用 inherit（继承宿主，永远对），边框用 currentColor。
输入框和按钮用低一层背景 bg-l1，暗色下才和容器分得开。
