fix(routes): 根因是 this 丢失——register 不能解构出来单独调

诊断日志是决定性的：
  webServer=yes register=function routeOk=true
  prefixes=map[1]:["/plugins"]     ← 注册完表里只有宿主自己的 /plugins

写成 const add = webServer.register; add(route) 时，this 是 undefined。
而宿主实现是 register(route){ const table = route.kind === 'exact' ? this.exact : this.prefixes; ... }
—— this 一丢就抛错，被我的 try/catch 吞掉，静默返回空函数。

所以「路由已注册」这句日志是假的：routeOk 只判断 register 是不是函数，
根本没判断注册有没有成功。注册失败从头到尾一个字都没留。

修：webServer.register(route) 直接调，保住 this。
并把「造 handler」和「注册」拆开（createRoutesHandler / registerRoutes），
猜错时至少能确定是哪一半。
